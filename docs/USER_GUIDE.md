# 星衡 OrbitLaser 使用说明

## 启动

将 Windows ZIP 解压到本地，双击 `OrbitLaser.exe`。程序内置引擎、资源及中文字体，启动后自动计算默认 6 小时 LEO → GEO 场景。

## 工作流

1. 右侧选择 LEO → GEO、LEO → LEO 或 GEO → GEO 预设。
2. 调整两颗卫星的半长轴高度、偏心率、倾角、RAAN、近地点幅角和平近点角。
3. 向下滚动右侧参数，设置时长、步长、功率、波长、口径、光束半角、指向角、效率、光子门限、噪声、偏差、时钟和种子。
4. 点击“运行仿真”。后台计算有进度，支持取消；取消会保留上一次结果。
5. 拖动轨道视图旋转，滚轮缩放。点击曲线或时间轴定位时刻，回放可选 1/10/60/300 倍。
6. 切换距离/残差和距离率/光子数曲线。
7. “测量数据”展示分页表格和有效采样窗口，点击数据行可定位时刻。
8. 顶部保存/打开 JSON 场景；载入后点击运行。“导出结果”保存 CSV，数据页可保存独立 HTML 报告。

修改输入而未重算时，导出仍对应上一次完成计算；状态栏会提示。无效测量在界面显示“—”，CSV 留空。

## 模型与单位

- 双体椭圆轨道，地球半径 6378.137 km、μ = 398600.4418 km³/s²。
- 半长轴高度为 a − 地球半径，范围 160–35786 km；偏心率 0–0.5，近地点须高于 100 km。初始相位是平近点角。
- 时间是相对历元，不关联特定 UTC 日期。角度为度，轨道为 ECI。
- 单向 A → B：迭代接收端运动的光行时影响，计算地球遮挡。
- 高斯远场光斑、口径截获、等效固定指向损耗、探测光子预算。假定理想捕获跟踪。
- 积分时间 = min(采样步长, 1 s)。光子数达到门限才生成有效测量。
- 伪距 = 光行时路径 + 固定测距偏差 + c·时钟偏差 + 高斯噪声。
- σ = sqrt[σ₀² + (c·σt/√N)²]，单向测量不使用双程 1/2 因子。
- 固定随机种子可复现数据。RMS 包含系统偏差，残差相对光行时路径。
- CSV 使用 UTF-8 BOM 和 SI 单位，列名包含单位。可用 Excel、Python、MATLAB 导入。
- 占比为采样点占比；窗口端点是有效采样时刻，不是精确连续可见性边界。
- 每次最多 50,000 点、最长 48 小时。

## 使用边界

用于概念设计、链路趋势和测量算法输入研究。未包含 J2/高阶引力、第三体、太阳辐射压、相对论、精密星历、姿态动力学、背景光、接收机饱和、热漂移或大气传播。不能替代经验证的高精度任务定轨工具，也不构成航天工程认证。

本次交付没有 Windows 真机环境；具体实测范围见 VALIDATION.md。若 Windows 无法启动，请记录系统版本、显卡驱动和错误信息以诊断，不要把关闭系统安全防护作为常规解决办法。
