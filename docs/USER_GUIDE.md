# 卫星轨道模拟仿真教学软件 · 使用说明

## 启动

Windows 10/11 64 位：解压程序包，双击“卫星轨道模拟仿真教学软件.exe”。内置引擎、中文字体和所有运行资源，无需安装开发工具、无需联网。显卡驱动需支持 OpenGL 3.3。

启动后自动计算分层星座：3 个轨道面、11 颗卫星，半长轴高度分别为 550、20200、35786 千米；22 条候选链路，6 小时、10 秒步长，共 47,542 条测量记录。

## 星座配置

右侧选择“低轨—中轨—同步”“低轨多面”或“同步高度”预设。选择要编辑的轨道面，可分别调整本面星数、半长轴高度、偏心率、倾角、升交点赤经、近地点幅角和首星平近点角。面内卫星按平近点角均匀分布。也可以添加和删除轨道面。

支持 2—8 个轨道面，每面 2—12 颗卫星，总星数不超过 72。半长轴高度范围为 160—35786 千米，偏心率不超过 0.5，近地点须高于地表 100 千米。不同高度用真实比例绘制，低轨星座在全星座视角中较小，可到“星座与组网”点击“低轨局部放大”，或滚轮缩放、拖动旋转。

相邻组网包含每面环形链路及相邻面对应星链路；全互联计算所有不重复星对。每条星对按列表箭头方向生成单向测量，不同时计算反向链路。链路为理想独立激光终端，不模拟终端数量、调度、捕获和姿态转动限制。

## 运行与分析

1. 设置星座和组网方式，按需设置采样、功率、波长、口径、发散角、指向抖动、探测效率、光子门限、噪声、时钟偏差及随机种子。
2. 点击“运行仿真”。计算在后台执行，可取消；取消后保留上一次完整结果。
3. 工作台顶部选择分析链路。指标、轨道高亮、快照、曲线和分页数据同步切换。
4. 用时间轴定位或回放，速度支持 1、10、60、300 倍。曲线可切换距离、残差、距离率和探测光子数。
5. “星座与组网”展示全部卫星和链路，汇总每条链路的有效率、距离范围与误差。双击任意链路返回工作台分析。
6. “测量数据”展示当前链路的逐点记录和有效采样窗口。

单条链路最多 50,000 个时刻，全网最多 300,000 条测量记录，仿真时长不超过 48 小时。超过限额时增加采样步长或减少星数、缩短时长；软件会给出明确提示。

## 保存和导出

“保存场景”记录所有轨道面、星数、组网和测量参数。“打开场景”载入后点击运行。兼容旧版双星场景，载入时扩展为两个多星轨道面。

“导出结果”导出全网测量数据，包含发射星、接收星、时间、几何距离、光行时路径、距离率、光行时、可见性、有效性、接收功率、光子数、噪声标准差、伪距和残差。CSV 使用带字节顺序标记的 UTF-8 编码，可用 Excel 导入；无效伪距和残差留空。

“分析报告”导出独立 HTML 文件，包含当前分析链路的输入、曲线与有效窗口，以及全网所有链路汇总。修改参数但未重新计算时，导出的是上一次完整结果，状态栏会提示。

## 模型与边界

采用地心惯性坐标中的开普勒双体传播、球形地球遮挡、迭代单向光行时、高斯光束口径截获及等效指向损耗。伪距包括光行时路径、固定偏差、接收端时钟偏差与高斯噪声，单向测量不使用双程测距的二分之一因子。每链路使用确定性的独立随机序列，场景可复现。

半长轴高度并非椭圆轨道的恒定离地高度；相位为平近点角。时间为相对历元，不对应具体日期。统计窗口端点是采样时刻，不是精确连续可见边界。均方根包含固定与时钟偏差。

本软件用于教学、概念分析及算法数据生成，不包含高阶引力、第三体、相对论、精密星历、背景光、真实姿态与终端动态，不替代任务级高精度定轨或工程认证。程序未数字签名；Windows 原生运行验收范围见 VALIDATION.md。
