## 默认场景结果

- 3 个轨道面，11 颗卫星，半长轴高度分别为 550、20200、35786 千米。
- 相邻组网 22 条候选链路，6 小时、10 秒步长，每链路 2161 个时刻，总计 47,542 条测量记录。
- 参考低轨至同步高度链路有效 1355 点，残差均方根约 0.019794689 米。
- 独立默认种子，每条链路按序号派生随机序列；重复计算可复现。

## 成品检查及限制

构建脚本已使用 Linux Godot 加载最终 Windows 文件的内嵌资源包，运行默认多星场景并检查成功结果，详见“验证记录/build-evidence.json”与“验证记录/packaged-smoke.json”。资源包包含多星模型和全部运行资源，测试脚本不随成品导出。

本次没有 Windows 真机，也没有执行 Windows 原生 EXE。跨平台资源包启动成功不等于 Windows 原生运行验收；Windows 可见窗口、DPI、原生文件框和安全软件兼容性尚未实测。程序没有数字签名。建议使用 Windows 10/11 64 位及支持 OpenGL 3.3 的显卡驱动。

教学模型采用双体轨道、球形遮挡、理想独立激光终端等近似；不包含终端调度、精密力学与高保真姿态。以上验证不构成航天工程认证。
