# 实际验证记录

当前交付测试环境：Debian GNU/Linux 13 x86_64，Godot 4.6.3 stable。图形界面使用 Xorg dummy 显示器、Mesa llvmpipe OpenGL 4.5 渲染。

| 测试组 | 已执行检查 | 结果 |
|---|---:|---|
| 数值模型 | 24 | 全部通过 |
| 导入导出 | 9 | 全部通过 |
| 真实渲染桌面集成 | 18 | 全部通过 |

数值检查包含圆轨道闭合、三时刻轨道能量守恒、解析弦长距离、遮挡与重合、近地点和采样限制、默认噪声统计、种子复现、编队距离率、单向时钟与固定偏差、光行时、CSV、无有效链路、GEO 全天有效窗口及取消。

导入导出检查包含 JSON 完整参数往返、格式与参数拒绝、文件读写、独立 SVG/HTML 报告、CSV 行列数及无效字段留空、零链路报告。

界面检查包含启动、布局、表格、时间定位、回放、四类曲线、页面导航、分页、LEO-LEO/GEO-GEO 预设、取消保留结果、JSON 保存载入、CSV/HTML 输出及第三方许可。

默认场景：2161 点、1355 条有效测量，残差 RMS 0.019794689 m，与对话中原实现记录一致。

## 成品检查

Windows 程序由官方 4.6.3 x64 release 模板交叉导出为 Windows GUI PE，PCK 内嵌，无外置脚本或字体依赖。应用图标写入现有资源区，不改变代码或 PCK 偏移。构建脚本在导出后加载成品资源包执行默认场景检查，结果记录在 build-evidence.json 中。

跨平台加载 Windows 内嵌资源包，**不等于 Windows EXE 原生运行**。本次未提供 Windows 主机或 Wine，因此未验证 Windows 可见窗口、原生文件选择框、显示缩放和安全软件兼容性。程序没有数字签名。

这属于开发与工程近似模型验证，不代表高保真任务定轨验证或航天工程认证。构建脚本会在 Windows 主机上执行原生 headless 成品检查；只有实际执行并取得结果后才能声称该项通过。
